AISHEROW — стартовый сайт студии
================================

Файлы:
- index.html — разметка (шапка, секции, подвал)
- style.css — стили + две темы (тёмная/светлая)
- script.js — переключатель темы

КАК ЗАПУСТИТЬ:
1. Положи логотип сюда под именем logo.png
2. Открой папку в VS Code
3. Установи расширение "Live Server" (если ещё нет)
4. ПКМ по index.html → "Open with Live Server"
5. Сайт откроется в браузере и будет обновляться сам при сохранении

КАК ВЫЛОЖИТЬ НА Vercel:
1. Создай репозиторий на GitHub и залей туда файлы
2. Зайди на vercel.com → "Add New Project" → выбери репозиторий
3. Жми Deploy — через минуту сайт в интернете 🎉
